## Stock APIs
Three stock APIs we can use are: 
- Alpha Vantage
- Finnhub
- Massive

### Free tier comparison:
|         | Alpha Vantage | Finnhub | Massive |
| ------- | ------------- | ------- | ------- |
| Rate limit | 25 calls / day | 60 calls / minute | 5 calls / minute |
| Real-time prices | No | Yes | No |
| Ticker search | Yes | Yes | Yes |
| WebSocket | No | 50 symbols | No | 
| Historical price data | 25+ years | None | 2 years |

### Cheapest premium tier comparison:
|       | Alpha Vantage | Finnhub | Massive |
| ----- | ------------- | ------- | ------- |
| Price | $50 / month   | $50 / month | $29 / month |
| Rate limit | 75 calls / minute | 150 calls / minute | Unlimited |
| Real-time prices | Delayed | Yes | Delayed |
| Bulk data | Yes | No | Yes |
| WebSocket | No | 250 symbols | Unlimited |
| Historical price data | 25+ years | 10 years | 5 years |
